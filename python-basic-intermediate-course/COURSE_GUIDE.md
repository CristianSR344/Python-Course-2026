# Course Guide

## Format

The course contains six two-hour sessions. Each uses roughly 30 minutes of demonstration, 35 minutes of exercises, 35 minutes of project work, and 20 minutes of review and assessment. Run notebooks top to bottom, then move to `.py` exercises.

## Learning path

| Session | Main concepts | Cumulative result |
|---|---|---|
| 1 | syntax, values, input, operators | employee badge and registration summary |
| 2 | conditions and loops | validated registration and access checking |
| 3 | collections | contact manager CLI |
| 4 | functions, modules, errors, files, JSON | persistent user file manager |
| 5 | classes, inheritance, composition | support ticket system |
| 6 | HTTP, FastAPI, Pydantic, SQLite | user-management portal |

Each lesson follows explain → simple example → realistic example → guided exercise → independent task → challenge → final-project connection. Solutions should be opened only after an honest attempt.

## Suggested workflow

Before class, complete `00_setup/environment_check.py`. During class, copy exercise files into a personal working branch. After each session, complete its quiz and project checkpoint. The final project rubric is in `assessments/final_project_rubric.md`.
