# Project Requirements

Build and demonstrate an administrative user portal. A user contains ID, first/last name, email, department, role, active state, creation time, and optional phone, employee ID, and comments.

Required workflows are dashboard totals/recent users; registration with email attempt; searchable list; details; edit; delete; and JSON GET/POST/PUT/DELETE endpoints. Validation errors and missing users must be understandable. Credentials stay in `.env`; email must fall back to local text files. The implementation must keep routes, business rules, persistence, and notification delivery in separate modules and pass the supplied tests.
