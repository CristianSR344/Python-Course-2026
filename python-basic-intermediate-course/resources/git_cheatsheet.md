# Git Cheat Sheet

```powershell
git status
git switch -c session-01-work
git add 01_fundamentals
git commit -m "Complete fundamentals exercises"
git log --oneline
git diff
```

Commit small working increments. Never add `.venv`, `.env`, databases, caches, or credentials. Before resolving a conflict, read both sides and run validation after the edit. Avoid destructive reset commands unless you understand exactly what will be lost.
